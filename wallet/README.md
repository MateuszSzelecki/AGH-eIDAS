# Tauri + SvelteKit + TypeScript

This template should help get you started developing with Tauri, SvelteKit and TypeScript in Vite.

What do you need to run it?

cargo
npm
Android Studio with NDK

that should be enough (not very sure about that :P)

For logs
adb logcat | grep -e Tauri/Console -e wallet_lib

where Tauri/Console are console.log() messages
and wallet_lib are rust log messages
